HTML-Template is an interactive reference for HTML, CSS and JavaScript. You look up a feature, see it running, edit the code in the browser and copy the result into your own project. Every demo shows the modern form of the feature together with the parts real projects need: accessibility, error handling and a fallback for browsers that lack it. The site is in English only.

The project is being rebuilt in seven stages. Stage 1 is the repository, the CI, the signed release pipeline and this wiki. The site itself, the editor and the topic pages come in later stages, so most pages here describe the design and say which parts exist so far. The [[Roadmap]] lists what each stage delivers.

## Status

The repository currently holds the policy checks, the CI workflows, the OpenSSF configuration and the release pipeline. The first signed release will be the pre-release `1.0.0-alpha.1`. Version 1.0.0 is published once every topic is done.
